## 📖 專題簡介 (Project Overview)
大眾衣櫃中普遍存在「丟掉可惜、穿出門又不知如何搭配」的閒置衣物。
《RE:CLOTHES 拾衣研究所》是一個為解決此痛點而設計的互動提案平台，運用商業設計美感與 AI 靈感生成，為每件衣物量身打造「痛點分析」、「風格穿搭公式」、「結構改造構想」以及「AI 生圖 Prompt 紀錄」。

---

## ✨ 核心特色與符合評分指南規範

1. **首頁精選案例牆**：
   - 每張卡片均呈現清楚的「**原單品 (Before) ➔ 改造／搭配方向 (After)**」對比。
   - 包含多種單品類別（襯衫、丹寧、T恤、西裝外套、洋裝、針織等）。
   - 支援單品類別篩選、難易度過濾與即時關鍵字搜尋。

2. **案例詳情頁 (Modal 彈窗)**：
   點進任一單品卡片，完整呈現 4 大核心板塊：
   - **一、 單品痛點分析**：深入剖析版型困境、材質特性與身材比例問題。
   - **二、 穿搭搭配建議**：提供 2~3 種不破壞衣物的日常穿搭層次公式。
   - **三、 結構改造構想**：分解工藝步驟 1-2-3、工具清單與設計師防失誤小撇步。
   - **四、 當時使用的 Prompt 紀錄**：保留當時生成該視覺提案的 Midjourney / AI Prompt，並提供「**一鍵複製 Prompt**」功能。

3. **自己的試用區 (AI 提案生成器)**：
   - 使用者可輸入自身衣物的名稱、材質、痛點、期望風格與偏好模式。
   - 提供「快速帶入範例」按鈕供現場評審或同學一秒試用。
   - 生成提案後，提供「**📥 將此提案儲存至上方案例牆**」按鈕，立即發布為新卡片！

4. **資料管理加分功能 (CRUD 滿分規劃)**：
   - **C (Create)**：可點擊「新增自訂案例」手動發布，或自試用區直接加入。
   - **R (Read)**：多維度檢視案例詳情、篩選與搜尋。
   - **U (Update)**：點擊任一卡片右上角編輯按鈕，彈窗修改即時生效更新。
   - **D (Delete)**：支援刪除案例，並具備確認對話框防誤觸。
   - **資料保存**：所有變更即時同步至瀏覽器 `localStorage`，重新整理不遺失。
   - **貼心備份**：提供「恢復預設範例」、「匯出 JSON」與「匯入備份」功能。

## 🌐 部署至 Vercel 步驟 (Deploy to Vercel)
專案已內建 `vercel.json` 與標準 `package.json`，支援 100% 零設定即時部署：

1. **建立 GitHub 公開專案庫**：
   - 由組長建立一個新的公開 repo（如 `idle-wardrobe-remake`）。
   - 將本資料夾內的所有檔案推入 `main` 分支。
2. **在 Vercel 匯入專案**：
   - 登入 [Vercel](https://vercel.com)，點擊「Add New Project」。
   - 選擇剛剛建立的 GitHub repo，點擊「Deploy」。
   - 數秒內即可獲得專屬公開網址（如 `https://idle-wardrobe-remake.vercel.app`）。
